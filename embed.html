B.A.R.T.O.L.O. — Embed Builder

Pick a date, then hit Copy on the full slate or any game and paste it into your post. The default Compatible layout is a plain, script-free iframe, so it works even in visual / rich-text editors (Action Network, WordPress visual mode, most CMSs) that strip out <script> tags. It carries data-autoresize="true" so platforms that support it grow the frame to fit; otherwise it shows at the height you set with a scrollbar, so nothing is ever cut off and nothing below it overlaps. Tap 📱 Mobile to preview the phone layout.
Want the frame to auto-fit its content exactly (no inner scrollbar)? Switch Layout to Auto-grow w/ script — but that only works in a true Custom HTML block that preserves <script> tags. If a signup form or ad still shows on top, that element is a page-level plugin overlay and must be turned off for the post.
